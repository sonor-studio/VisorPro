# Security Policy

## Supported Versions

Currently, only the latest release of VisorPro receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main Branch | :white_check_mark: |
| Older builds | :x:                |

## Reporting a Vulnerability

Security is a top priority for VisorPro. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to us via email at:
**sonor.app.studio@gmail.com**

Please include the following in your report:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant logs, crash reports, or screenshots.

We will review the vulnerability and respond as quickly as possible. We will keep you informed of our progress towards a fix and coordinate any public announcement with you.
